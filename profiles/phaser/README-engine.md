# Perfil Phaser

Requiere una version exacta de Node.js LTS acordada por la materia o el equipo y registrada en `docs/project-manifest.md` antes de inicializar. Desde `game/`, ejecuta `npm ci` y luego `npm run dev`. Usa `npm run build` para comprobar TypeScript y generar la build de produccion.

Documentacion oficial:

- [Phaser Vite TypeScript Template](https://github.com/phaserjs/template-vite-ts)
- [Phaser documentation](https://docs.phaser.io/)
