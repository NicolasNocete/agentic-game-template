# Guia de la Plantilla

## Objetivo

Esta plantilla ayuda a construir vertical slices academicas: experiencias breves que muestran un core loop, objetivo, feedback y cierre jugable.

## Inicio rapido

1. Crea una copia del repositorio.
2. Ejecuta `/bootstrap` con el motor elegido.
3. Abre el juego y comprueba que ejecuta.
4. Completa el contrato de vertical slice.
5. Crea tareas pequenas y una spec cuando el cambio lo necesite.

## Alcance sugerido

- Entre 5 y 15 minutos de experiencia jugable.
- Una mecanica central y hasta dos mecanicas de apoyo.
- Un nivel, arena o conjunto reducido de pantallas.
- Inicio, objetivo, resultado y reinicio.

Evitar inicialmente multijugador, servicios online, mundo abierto, economias extensas, multiples modos y sistemas sin relacion directa con el core loop.
