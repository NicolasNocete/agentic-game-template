# Understand Game Repository

## Procedure

1. Read the project manifest, README, AGENTS file, and engine guide.
2. Detect the engine from project files when the manifest is incomplete.
3. Explain prerequisites, exact run steps, entry point, and first verification in Spanish.
4. Identify folders for code, scenes or levels, assets, specs, tasks, and tests.
5. State missing information instead of guessing.

## Output

Use headings: `Como ejecutar`, `Donde trabajar`, `Primera verificacion`, and `Informacion faltante` when applicable.
