# Engine Docs Lookup

## Procedure

1. Read `docs/project-manifest.md` to identify the engine and version.
2. Read `docs/engine-guide.md` first.
3. Prefer official documentation and version-specific pages.
4. Return a short Spanish explanation, official links, and any version caveat.
5. Do not invent APIs, commands, or project configuration.
