# Contributing

## Scope

Contributions should improve the academic workflow, an engine profile, a command, a skill, or a documented reference.

## Rules

- Keep profiles minimal and runnable.
- Prefer official engine documentation for technical references.
- Add public sources for design, UX, accessibility, or educational guidance.
- Do not add CI, deployment, or external services unless the template scope changes.
- Test a command or profile manually before proposing it.
- Keep command names in English and student-facing text in Spanish.
